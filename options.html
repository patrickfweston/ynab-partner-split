YNAB Partner Split – Configuration

Set your YNAB API details and splits. Each split is another party; the transaction is divided equally among your category and each split's category. The popup lets you choose the category for your share each time you split.

YNAB API

Splits

Add one or more splits (e.g. Partner A, Partner B). The transaction is split equally among your category and each split's reimbursement category.

Use {partner_names} for the list of split names, or {partner_name} for a single split.

Behavior

Append to existing memo When enabled, the split memo is added after any existing memo (with a comma). When disabled, the split memo replaces the existing memo. Default: append.
Reload YNAB tab after split When enabled, the extension reloads the YNAB page after splitting so you see the updated transactions without refreshing manually.
